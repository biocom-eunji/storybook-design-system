<div className="platform-note">
<strong>⚠️ React Native 호환성</strong>: React Native의 shadow API는 <code>spread</code>를 지원하지 않습니다. RN 컴포넌트에서는 <code>shadowTokensV2.{`{level}`}</code>의 <code>offsetX/offsetY</code>, <code>opacity</code>, <code>blur</code>(=<code>shadowRadius</code>), <code>elevation</code>(Android)만 사용하세요. 웹 Storybook은 <code>css</code> 필드로 spread 포함 box-shadow를 렌더링합니다.
</div>

## 사용 예시

### React Native
```typescript
import { shadowTokensV2 } from '@/tokens/theme';

const styles = StyleSheet.create({
  modal: {
    shadowColor: '#000000',
    shadowOffset: { width: shadowTokensV2.level3.offsetX, height: shadowTokensV2.level3.offsetY },
    shadowOpacity: shadowTokensV2.level3.opacity,
    shadowRadius: shadowTokensV2.level3.blur,
    elevation: shadowTokensV2.level3.elevation, // Android
  },
});
```

### Web (Storybook 등)
```typescript
import { shadowTokensV2 } from '@/tokens/theme';

const modalStyle = {
  boxShadow: shadowTokensV2.level3.css, // '0px 4px 16px 8px rgba(0,0,0,0.15)'
};
```
